# Steel-Gym-Client-Registration-System
Sistema web para digitalizar el proceso de inscripción de clientes de Steel Gym.

## Descripción

Este proyecto nace como una solución para reemplazar el proceso actual de inscripción en papel utilizado por Steel Gym.

Actualmente, los nuevos usuarios llenan una ficha física con sus datos personales, información médica y contactos de emergencia. El objetivo de este proyecto es desarrollar una versión digital que facilite el registro, mejore la organización de la información y siente las bases para un futuro sistema de administración del gimnasio.

## Objetivos

- Digitalizar el formulario de inscripción.
- Mejorar la experiencia de registro para nuevos clientes.
- Centralizar la información de los usuarios.
- Reducir el uso de formularios impresos.
- Preparar el proyecto para futuras integraciones con bases de datos y backend.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Funcionalidades

- Registro de información personal.
- Registro de contacto de emergencia.
- Cuestionario de salud.
- Validaciones utilizando HTML5.
- Interfaz limpia y fácil de utilizar.
